## 唯一失败项说明（RAG 检索质量）

- 失败断言共 3 条，全部出自**语义泛化**子场景（查询不含任何关键词，需向量路召回）：
  - `语义查询 top1 命中权威文档`
  - `top1 文本含目标事实`
  - `向量路参与召回（bm25 词面完全不匹配）`
- 根因：嵌入接口返回 `HTTP 429 code=1113 Insufficient balance or no resource package`，向量无法生成，向量路降级为纯 BM25。这不是代码缺陷——BM25 词面匹配场景下 5/5 召回正常，只有必须靠向量的语义泛化场景失败。
- 修复动作：给嵌入服务（z.ai embedding）充值即可，无需改代码。充值后重跑 `scripts/test_rag.py` 预期 6/6。
- 评测集防线（64/64）与其余 30 项不受影响。
