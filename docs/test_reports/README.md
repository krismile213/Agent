## RAG 红项修复记录（11-16 → 11-17）

- 11-16 失败根因：远程嵌入接口 `HTTP 429 code=1113` 欠费，向量路降级纯 BM25，语义泛化 3 条断言失败（非代码缺陷）。
- 11-17 两步修复（均未改核心业务逻辑）：

- 结论：**不再需要给嵌入服务充值**；此前"充值即可"的说法已作废。
