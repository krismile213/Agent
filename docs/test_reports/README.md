## 口径漂移告警（11-17）

- 目的：给"业务规则数字"装 CI，防止真源被偷改或静默回退（如漏导出导致 Part1 回退 75，数值不变但来源变）。
- 实现：`rules/drift_check.py`（纯函数三查：值漂移/来源回退/hash 漂移）+ `drift_probe.py`（IO 探针，失败静默降级）+ `daily_brief.finish()` 收尾关卡（⑥ 暂缓催办）。
- 已知豁免：Part1 膜 13(快照) vs 75(xlsx) 是用户拍板差异，不误报；壳 Part1=75 独立基线。
- hash 基线 `drift_baseline.json`（gitignore，按品类分键，首次只建基线）；与新鲜度守卫冲突时后者优先。
- 设计说明见 `docs/口径漂移告警.md`；体检脚本 `python drift_probe.py`。

## LLM Wiki POC（11-17，旁路验证）

- 目的：验证 Karpathy LLM Wiki 模式能否替代现有 RAG。结论：**不能替代，可作 L1 稳定底座旁路引入**。
- 实现：`plugins/knowledge_wiki.py`（纯标准库、零 LLM 依赖、不 import rag）；5 权威源→66 概念页；编译幂等、只读源、固化别名不含答案数字。
- 同评测集 6 条对比：Wiki top1 5/6、召回 6/6、事实可见 5/6；RAG top1 4/6、召回 6/6、事实可见 6/6——互有胜负。
- 详细分析见 `docs/LLM-Wiki-POC对比报告.md`。对比脚本 `scripts/eval_wiki_vs_rag.py`（只读）。
