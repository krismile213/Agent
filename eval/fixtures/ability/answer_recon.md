# Q3销售数据核对结果

## 核对方法
- orders_q3.csv：销售明细表，按SKU逐行记录销售数量
- summary_q3.csv：汇总表，按SKU汇总销售数量
- 对每个SKU的明细合计与汇总表进行逐个对比

## 核对结果

### 一致的SKU
- SKU-A：明细合计60，汇总值60 ✓
- SKU-B：明细合计40，汇总值40 ✓  
- SKU-C：明细合计60，汇总值60 ✓
- SKU-E：明细合计42，汇总值42 ✓

### 不一致的SKU
- **SKU-D**：
  - 明细合计：95
  - 汇总值：105
  - 差值：-10

## 结论
共发现1个SKU数据不一致：SKU-D的明细合计比汇总值少10。
